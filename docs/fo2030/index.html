    05 / CANOPY PORTFOLIO DATA · 亚洲家办投资偏好

    亚洲家办的钱，大部分不投亚洲

    美元资产为主 · 私募股权重仓 · 稳步转向另类

    01配置结构

  • 股票是第一大类资产
  • 另类投资与固收规模相当
  • 现金留得足，是刻意保持的流动性仓位

    • 02地域与币种

  • 近半资产配置在美国，美元占绝对主导
  • 欧洲布局多为基金注册地（卢森堡/爱尔兰），实质敞口有限
  • 投回亚洲的比例仅约五分之一

    • 03另类投资

  • 私募股权约占另类资产五分之四
  • 高度个性化：多数基金单一家族持有，罕有共识标的

    • 04行为特征

  • 过去一年，另类占比近翻倍，美元资产持续攀升
  • 调整逐月渐进，无急转弯，不追热点
